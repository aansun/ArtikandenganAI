# NNAI Translator 1.0.8

See where each book stands, continue after closing the app, and keep names the same across a series.

## New

- **Three stages above the title** on the Progress screen: Glossary & style, Translation, Polish. Each shows
  whether it is done, running, paused, waiting or skipped, and **how long it has taken**. Times are counted
  from this version on.
- **Volumes share names and style.** A volume you add starts from the glossary and the writing style of the
  other books of its series already in your library, in the same target language, in whatever order you add
  them. The series is read from the book's details, title or file name ("Vol. 2", "Book 3", "Jilid 4"), and
  the author must match. A book that states no series is not linked. A deleted book no longer passes anything on.
- **Delete a book from the library.** A warning lists what goes with it (translations, the copy of the original
  file, glossary, style, saved progress) and what stays. The folder is moved to the Trash. A book in the queue
  cannot be deleted.
- **Writing style: Manual or Automatic** (Settings). Manual, the default, waits for you to confirm each book's
  style and names, now for non-fiction too. Automatic uses the recommended style and starts right away.

## Continue where you stopped

- A book stopped by a pause or by closing the app keeps its card, percentage, stage times and a **Resume**
  button.
- **The polish pass no longer starts over.** Polished passages are kept and not asked for again.
- A glossary that was being built keeps the answers it already had.
- Only the request in flight when the app closed is repeated.

## Changed

- Softer, warmer colours in light and dark.

## Updating while a book is being translated

The translation itself continues after the update. If a book was being **polished** by an earlier version, that
polish pass starts once more from the beginning, because earlier versions did not keep it. To avoid that, update
when the running book has finished.

## Install

Download `NNAI-Translator-1.0.8.dmg`, open it and drag the app to Applications (replace the old copy). Quit the
old app first so it can stop its engine cleanly; the queue resumes when you open the new one, unless you had
paused it. Your settings, library and the Python libraries installed on first launch are kept.
`NNAI-Translator-1.0.8.zip` holds the same app and is what the in-app updater downloads.

## Please buy the books

This tool only helps you read a book you legitimately own in a language you understand. Buy the official
edition, and the official translation when there is one. Do not share or sell the translations it makes.
