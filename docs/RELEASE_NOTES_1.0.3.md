# NNAI Translator 1.0.3

A small release for the project's new name. The repository is now
[aansun/NNAI-Translator](https://github.com/aansun/NNAI-Translator).

## Changed

- **The GitHub link and the update check use the new repository address.** The About window, the GitHub row
  in Settings and the in-app updater point at `aansun/NNAI-Translator`. Older versions keep working, because
  GitHub redirects the old address.

Nothing else changed since 1.0.2: the queue still resumes by itself after a restart, and each book keeps its
own cover on every screen.

## Install

Download `NNAI-Translator-1.0.3.dmg`, open it and drag the app to Applications (replace the old copy). Quit the
old app first so it can stop its engine cleanly; the queue resumes when you open the new one. Your settings,
library and the Python libraries installed on first launch are kept. `NNAI-Translator-1.0.3.zip` holds the same
app and is what the in-app updater downloads.

## Please buy the books

This tool only helps you read a book you legitimately own in a language you understand. Buy the official
edition, and the official translation when there is one. Do not share or sell the translations it makes.
