# NNAI Translator 1.1.2

A log for Send to Kindle, to find out why a send fails.

## New

- Each **Test connection** and each send is written to a log on your Mac: time, app version, mail server,
  the step that failed, the server's reply and, for Gmail, whether the stored password has the shape of an
  app password. It holds no password, e-mail address, title or file path, keeps the last 300 lines and is
  not sent anywhere. Open or copy it under **Settings > Send to Kindle > Sending log**.
- When Gmail asks for an **app password** instead of the account's password, the app now says so.
- A button next to the password opens Google's page for making an app password.

## Install

Download `NNAI-Translator-1.1.2.dmg`, open it and drag the app to Applications (replace the old copy). Quit the
old app first so it can stop its engine cleanly; the queue resumes when you open the new one, unless you had
paused it. Your settings, library and the Python libraries installed on first launch are kept.
`NNAI-Translator-1.1.2.zip` holds the same app and is what the in-app updater downloads.

## Please buy the books

This tool only helps you read a book you legitimately own in a language you understand. Buy the official
edition, and the official translation when there is one. Do not share or sell the translations it makes.
